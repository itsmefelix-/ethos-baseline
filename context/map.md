# ethos-baseline Library Map

| Path | Purpose |
| --- | --- |
| `context/` | Mission snapshot, interview, and directory map for ethos-baseline. |
| `planning/` | Roadmap, schema, and interview template. |
| `docs/` | TELOS, specs, research, and supporting references. |
| `data/` | Raw inputs and derived metrics feeding the project. |
| `tools/` | Scripts/utilities that transform or analyze data. |
| `exports/` | Generated dashboards, JSON summaries, public artifacts. |
| `reports/` | Pipeline status and validation logs. |
| `inbox/` | Raw drops awaiting ingestion (optional). |
| `portal/` | Web/API service exposing project data (optional). |
| `scripts/` | CLI helpers for automation (optional). |
